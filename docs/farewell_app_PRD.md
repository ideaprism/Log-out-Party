## 1. 한 줄 정의

26년의 근속을 **존속기간이 만료된 특허 한 건**으로 공고하는 모바일 청첩장형 페이지. 동료들은 마지막 출근일 12:50에 **라이브 OX**로 함께 놀고, **의견서(롤링페이퍼)**를 남긴다.

### 1.1 세계관

| 특허 | 송별 |
|---|---|
| 존속기간 | 26년 근속 (법정 20년 + α) |
| 존속기간 만료 | 자발적 명예퇴직. 기간을 다 채우고 끝남 |
| 【심사】 | 12:50 라이브 OX |
| 의견서 | 롤링페이퍼 |
| 만료 후 자유 실시 | "이제 누구나 자유롭게 연락하세요" |
| 다음 출원 | 인생 2막 (IdeaPrism) — 엔딩에서만 공개 |

### 1.2 구성 — 두 개의 시스템, 하나의 QR

```
게시판 글 + QR
   └─ ① 존속기간 만료 안내 앱 (farewell-ck.vercel.app · Vercel + Supabase)
        ├─ 표지 · 감사 편지 · 타임라인
        ├─ 【심사 공고】 카드 ──12:45 입장──▶ ② KIPlay_OX Farewell 특별 회차 (Render)
        │                                      12:50 Q1 → 서바이벌 → 우승자 1명
        ├─ 의견서 작성 · 피드  ← 창균님 선정 2편
        └─ 엔딩 (자유 실시 · 다음 출원 · 스티브 창스)
```

| 구분 | ① Farewell 앱 | ② 라이브 OX |
|---|---|---|
| 성격 | 비동기, 언제든 열람 | 동기, D일 12:50 한 번 |
| 기반 | 신규 개발 | KIPlay_OX 엔진 그대로 (설정·문항만 교체) |
| 호스팅 | Vercel + Supabase | Render 상시 프로세스 |
| 식별 | 이름 + 부서 | 사번 5자리 (KIPlay 방식, 서버 메모리에만 존재) |
| 상품 | 롤링페이퍼 5만 원 × 2 | 우승 10만 원 × 1 |

## 4. ① Farewell 앱 — 화면 구성

청첩장처럼 위에서 아래로 내려 읽는 스크롤형. 섹션 제목은 공보의 INID 코드·표제를 따른다.

| 순서 | 섹션 | 공보 장치 | 내용 |
|:-:|---|---|---|
| 0 | 링크 미리보기 | OG 이미지 | 공보 1면 썸네일 + "존속기간 만료 안내 · 굿바이 KIPI, 헬로 월드" |
| 1 | 표지 | (19)(12)(11)(45)(54)(72)(73) + 존속기간 | (19) 대한민국 지식재산처(KR) / (12) 존속기간 만료 안내 / (54) 함께한 26년 / (72) 발명자: 정창균 / **(73) 특허권자: 한국특허정보원 동료 여러분** / 존속기간 2000. ~ 2026. (26년 · 법정 20년 + α) / 대표도: 캐리커처 |
| 2 | 감사 편지 | (57) 요약 | 3~5문단. 입사 장면 → 고마운 순간 → 남는 동료에게 |
| 3 | 26년 타임라인 | 【도 1】 | 2000 입사(특허기술정보센터) → 2002 독립 재단 → … → 2026 |
| 4 | 라이브 OX 안내 | 【심사 공고】 | 시각별로 바뀌는 카드 (4.1) |
| 5 | 의견서 작성 | 【의견서】 | 이름·부서·메시지, 공개/비공개 |
| 6 | 의견서 피드 | 【의견서 목록】 | 공개 의견서 카드. 선정 2편은 맨 위 + 登 도장 |
| 7 | 엔딩 | 자유 실시 · 다음 출원 | 4.4 카피 덱 순서대로 |

### 4.1 【심사 공고】 카드 — 시각에 따라 자동 전환

| 시각 (D일) | 카드 상태 | 표시 |
|---|---|---|
| ~ 12:45 | 예고 | "12:50, 마지막 심사가 열립니다" + 카운트다운 + 규칙 3줄 + 상품(우승 10만 원) |
| 12:45 ~ 12:50 | 입장 | **[심사장 입장]** 버튼 → 라이브 OX 주소 새 창. "사번 5자리로 입장" 안내 |
| 12:50 ~ 진행 중 | 진행 | "심사 진행 중 — 지금 입장하면 관전만 가능합니다" + 입장 버튼 유지 |
| 종료 후 | 결과 | "등록 결정: ○○○님" (관리자가 입력한 우승자 이름) |
| D일 외 | 기록 | 결과만 남김 |

### 4.2 의견서 (롤링페이퍼)

| 항목 | 규칙 |
|---|---|
| 입력 | 이름(필수), 부서(선택 목록 + 기타), 메시지(필수, 300자) |
| 공개 범위 | `공개`(기본) / `창균님만 보기` |
| 수정·삭제 | 같은 기기에서. 수정은 작성 후 24시간 내, 삭제는 언제든 (선정된 글은 삭제 불가) |
| 관리 | 관리자 숨김(삭제 대신). 공개 피드 노출 전 별도 승인은 없음 |
| 안내문 | "링크를 아는 사람은 공개 의견서를 볼 수 있습니다" 입력창 위에 상시 표시 |

### 4.3 상품

| 상품 | 대상 | 선정 | 발표 |
|---|---|---|---|
| 10만 원 × 1 | 라이브 OX 우승자 | KIPlay_OX 엔진 (서바이벌 → 서든데스) | 회차 종료 직후. 앱 카드에 이름 표시 + 게시판 댓글 |
| 5만 원 × 2 | 의견서 작성자 | **창균님이 직접 선정** (마음에 남는 2편) | D일 퇴근 전. 피드 맨 위에 登 도장으로 표시 + 게시판 댓글 |

| 규칙 | 내용 |
|---|---|
| 선정 대상 마감 | D일 16:00까지 제출된 의견서 (선정 후 발표 시간 확보) |

| 상품 전달 | 개별 연락 (카카오페이·모바일 상품권 등, 창균님 결정) |

## 5. ② 라이브 OX — KIPlay_OX Farewell 특별 회차

엔진 코드는 고치지 않는다. **문항 파일, 명부 1행, 시작 시각**만 바꾼다.

### 5.1 회차 진행

| 시각 | 진행 | 엔진 기능 |
|---|---|---|
| 12:40 | Render 서버 깨우기, 운영자 화면 접속 | 무료 플랜은 15분 무활동 시 잠듦 |
| 12:45 | 대기실 개장 (프리쇼 5분, 로고송) | 운영자 화면에서 대기실 300초로 **게임 시작** |
| 12:50 | 1번 문항 | |
| ~12:56 | 최대 10문항 → 필요 시 서든데스 → 우승자 1명 | 회차 예산 6분 |
| 우승 직후 | 우승 공보 카드 (`ending.js`) | 우승자는 이 카드를 캡처해 수령 증빙으로 제출 |

**시작 방식:** 정기 자동 개장(월요일 12:55)은 D일 요일과 다를 수 있으므로 **운영자 화면 수동 시작을 기본**으로 한다. 환경변수(`GAME_DOW`·`GAME_HOUR=12`·`GAME_MINUTE=50`)를 D일에 맞춰 두는 것은 백업. 환경변수 변경은 재배포를 부르므로 D-1에 해 둔다.

### 5.2 바꾸는 것

| 항목 | 변경 | 위치 |
|---|---|---|
| 문항 | Farewell 세트로 교체 (임시안: `questions.farewell.json`) | `data/questions.json` 교체 후 push, 또는 `/api/admin/reload` |
| 스페셜 게스트 | 창균님 사번 1행 추가, `vip: true`, `title: "오늘의 주인공"` | `data/employees.json` roster |
| 운영자 키 | D일 전용 새 키 | Render 환경변수 `ADMIN_KEY` |
| 호스팅 | D일만 유료 플랜 전환 또는 12:40 사전 기동 | Render 대시보드 |
| 회차 후 | 원래 문항 파일 복구 | git |

### 5.3 문항 구성

엔진은 최대 10문항을 **쉬움 2 → 보통 2 → 어려움 6** 순으로 뽑고, 같은 난이도 안에서는 무작위다. 그래서 분류를 난이도에 대응시킨다.

| 순서 | 난이도 | 분류 | 의도 |
|---|---|---|---|
| Q1~2 | 쉬움 | 덕담 | 워밍업. 거의 전원 생존 |
| Q3~4 | 보통 | 회사공지 | 기관 소식을 읽은 사람이 유리 |
| Q5~10 | 어려움 | 특허상식 3 + 정창균 퀴즈 3 | 탈락이 몰리는 구간. 정창균 퀴즈는 찍기 요소 |
| 서든데스 | 숫자 | 정창균 / 특허 숫자 | 동점 처리 |

임시 문항은 `questions.farewell.json` 참고. **[확인필요]** 표시 문항은 창균님이 사실관계 확정 후 수정.

### 5.4 우승자 확인

| 문제 | 대응 |
|---|---|
| 명부에 없는 사번은 "직원 26005"처럼 표시됨 | 우승자는 사번으로 표시됨. 창균님이 사내 시스템으로 사번 → 이름 확인 후 앱에 이름 입력 |
| 아무 5자리나 입력해 여러 번 참여 가능 | 상품 지급 전 사번 본인 확인 + 우승 공보 카드 캡처 대조. 가짜 사번 우승은 무효 |
| 동일 사번 중복 접속 | 엔진이 이전 세션을 끊음 (기존 기능) |

| 계층 | 선택 | 이유 |
|---|---|---|
| 프론트 | Next.js (App Router) on Vercel | IdeaPrism과 같은 스택, OG 이미지 생성 |
| 저장소 | **Upstash Redis** (Vercel Marketplace 연동, 무료 플랜) — v1.3 변경 | 짧은 글 100건 규모라 스키마·RLS가 필요 없음. 로컬 개발은 `.data/store.json` 파일 어댑터 |
| 쓰기 | Next.js 서버 라우트에서만 (검증·속도 제한 후 Redis 기록) | 토큰은 서버에만. 브라우저는 저장소에 직접 닿지 않음 |
| 관리자 | `/admin` + 환경변수 비밀키 (httpOnly 쿠키) | 키를 저장소에 두지 않음 |

비동기 페이지라 서버리스로 충분하다. KIPlay_OX가 Vercel을 피한 이유(동기 게임 상태가 인스턴스마다 갈라짐)는 이 앱에 해당하지 않는다.

### 6.2 데이터 모델

> v1.3: 아래 SQL은 **논리 모델**이다. 실제 저장은 Redis 키(`config` 해시, `msg:{id}` 해시, `feed` 정렬 집합 등)로 하며, 아래 6.3의 함수는 Next.js 서버 라우트(`/api/*`)로 구현한다. 본인 의견서는 수정(24시간 내)과 삭제를 모두 지원한다.

```sql
create table event_config (
  id int primary key default 1 check (id = 1),
  d_day date,                         -- 마지막 출근일 (미정이면 null → 예고 카드만)
  publish_at timestamptz,             -- 게시 시각 (이전엔 관리자만 열람)
  live_open_at  timestamptz,          -- 12:45 입장 버튼 활성
  live_start_at timestamptz,          -- 12:50
  live_url text,                      -- KIPlay_OX 주소
  live_winner_name text,              -- 관리자 입력
  pick_deadline_at timestamptz        -- 16:00 선정 대상 마감
);

create table messages (
  id uuid primary key default gen_random_uuid(),
  device_token text not null,
  name text not null,
  dept text,
  body text not null check (char_length(body) <= 300),
  visibility text not null default 'public' check (visibility in ('public','private')),
  hidden boolean not null default false,
  picked boolean not null default false,   -- 창균님 선정
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
```

### 6.3 RPC

| 함수 | 동작 |
|---|---|
| `submit_message(device_token, name, dept, body, visibility)` | 신규 작성 |
| `edit_message(id, device_token, body, visibility)` | 같은 기기, 작성 24시간 이내만 |
| `public_feed(cursor)` | `public and not hidden`, 선정 2편 먼저, 이후 최신순 |
| `admin_*` (서버 라우트 전용) | 숨김, 선정(최대 2편, `created_at < pick_deadline_at`만), 우승자 이름 입력 |

### 6.4 상태 (시각 기준, 수동 버튼 없음)

```
[PREVIEW] ─publish_at─▶ [OPEN] ─live_open_at─▶ [LIVE] ─우승자 입력─▶ [AFTER]
 관리자만      예고 카드        입장 버튼            결과 카드 · 의견서 계속
```
