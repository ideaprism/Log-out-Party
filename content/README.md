# content/ — 글만 바꾸는 곳

코드를 몰라도 이 폴더의 파일만 고치면 화면 문구가 바뀝니다. 저장 → `git push` → Vercel이 자동 배포합니다.

| 파일 | 화면 위치 | 고치는 법 |
|---|---|---|
| `cover.json` | 1쪽 표지 (공보 1면) | 따옴표 안의 값만 바꾼다 |
| `letter.md` | 2쪽 (57) 요약 = 감사 편지 | 빈 줄로 문단을 나눈다. `—`로 시작하는 문단은 서명 |
| `timeline.json` | 3쪽 【도 1】 흐름도 | `items`에 `{ "year", "title", "note" }`를 더하거나 뺀다 |
| `copy.json` | 심사 공고 · 의견서 · 엔딩 문구 | PRD 4.4 확정 문구. 배치 규칙은 `_note` 참고 |
| `contact.json` | 엔딩 [연락처 저장] 버튼 (vCard) | 화면에는 번호가 나오지 않는다 |
| `links.json` | 엔딩 ② 다음 출원 링크 | IdeaPrism 링크는 여기 한 곳만 |
| `departments.json` | 의견서 부서 선택 목록 | 조직도에 맞게 고친다 |

## 규칙

- `[확인필요]`라고 적으면 화면에 점선 표시가 붙습니다. 사실을 확인한 뒤 지우세요.
- `{time}`·`{n}`처럼 중괄호로 싼 자리는 화면에서 시각·숫자로 바뀝니다. 문장은 고쳐도 이 자리는 남겨 두세요.
- `_note`로 시작하는 키는 설명용이라 화면에 나오지 않습니다.
- JSON은 쉼표·따옴표 하나만 틀려도 빌드가 멈춥니다. 빌드가 실패하면 마지막으로 고친 줄부터 보세요.
  (형식이 틀리면 `npm run dev` 화면에 어느 파일 어느 칸이 틀렸는지 나옵니다.)
- 캐리커처는 `public/caricature.svg`를 같은 이름의 파일로 바꾸거나, `cover.json`의 `figure.src`를 새 파일 경로로 바꿉니다.
